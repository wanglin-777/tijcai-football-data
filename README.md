# 中国体彩 · 竞彩足球每日数据

由 `Sync-TijcaiData.ps1` 自动抓取并推送。

- 数据来源：中国体彩网官方接口 `webapi.sporttery.cn`（竞彩足球）
- 更新频率：每日一次（赛果 + 在售赛事赔率快照）

## 目录结构

```
data/
  index.json                        # 所有已抓取日期的索引
  results/2026/2026-11-09.json      # 当日赛果（原始结构 + 扁平字段）
  results/2026/2026-11-09.csv       # 当日赛果（表格版）
  odds/2026-11-09.json              # 当日「在售赛事」赔率快照
  odds/2026-11-09.csv
```

## 字段说明（赛果）

| 字段 | 说明 |
| --- | --- |
| 场次 | 竞彩场次编号，如 `周日030` |
| 联赛 | 联赛简称，如 `西甲` |
| 半场比分 / 全场比分 | 如 `1:1` / `1:2` |
| 胜平负 | 全场赛果：主胜 / 平 / 客胜 |
| 让球 | 让球数，如 `+1` |
| 让球胜/平/负赔 | 让球胜平负玩法赔率 |
| 单关 | 是否支持单关投注 |

> 声明：数据版权归中国体育彩票所有，本仓库仅用于学习与研究，不构成任何投注建议。
